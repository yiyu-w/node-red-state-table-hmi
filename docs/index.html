Browser preview of a Node-RED screen built with FlowFuse Dashboard. It runs the same template, function nodes and wiring as flows.json. In the running flow the reading is evaluated by the Node-RED server; here that same function runs in your browser. Source and setup: github.com/yiyu-w/node-red-state-table-hmi

The state table this screen is generated from

Everything machine-specific lives in this array. The screen has no knowledge of what a reactor is: replace the table and you get another machine's screen with the same interaction, the same colour meanings and the same reset vocabulary.
