Infeed recovery

Browser preview of a Node-RED screen built with FlowFuse Dashboard. It runs the same template, state-table function and wiring as recovery/flows.json; in the running flow that function runs on the Node-RED server. Use Simulate to raise the Infeed PE jammed warning or fault, then Reset. Conditions, corrective actions and reset rules are taken from the public ISC CAM Troubleshooting and Reference Manual (v2.x). The one open cell is who may act. A demonstrator for testing the interaction, not a replacement HMI. Source: github.com/yiyu-w/node-red-state-table-hmi/recovery · measurement-point screen

The state table this screen is generated from

Everything condition-specific lives here: what it means, what to do, what triggers it, how reset works and who may act. The screen holds no machine knowledge; add rows and the same card serves the next condition.
